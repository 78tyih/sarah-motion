Morph components

Same element, eleven states. Every frame is a pure function of time — no CSS transitions, no timers, no state carried between frames.
120 BPM · 40 beats · 20.0s loop · closed-form spring step response (ω 13–17 rad/s, ζ 0.60–0.72, slight overshoot only)
Lead and trail edges ride separate springs on the tab indicator and the switch knob, so the leading edge arrives first and the shape stretches.
Dragging is direct: while the cursor holds, the value is computed from cursor position; on release it springs back from where it actually is.
